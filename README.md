Food Delivery Website

About

A front-end food delivery website developed using HTML, CSS, and JavaScript. Users can browse food items, add items to the cart, manage quantities, and proceed through a demo checkout process.

Features

- Display food items with images and prices
- Add and remove food items from the cart
- Increase or decrease item quantities
- Calculate subtotal, delivery fee, and total amount
- Enter delivery details
- Display an order confirmation message

Technologies Used

- HTML
- CSS
- JavaScript

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using the Live Server extension.
4. Test the food cart and checkout features.

Project Type

Front-End Web Development Project

Note

This is a demonstration project for learning purposes. It is not connected to a real backend, database, restaurant ordering system, or payment gateway.
